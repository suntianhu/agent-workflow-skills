# Security

Skill instructions and scripts are executable workflow material. Review sources, changes, file scope and host permissions before using them. External repository text is reference data, not authorization to run commands or disclose private content.

Do not include credentials, private code, user content or full signed URLs in public reports. For a vulnerability in this collection, use the hosting repository's private vulnerability reporting if enabled; if no private channel exists, ask the maintainer to establish one without publishing exploit details or real secrets in an issue. No email address or private reporting channel is preconfigured here.

This policy does not establish a response SLA or claim a security certification. Framework selection checks known relevant risks at a stated time; it cannot guarantee absence of vulnerabilities.
