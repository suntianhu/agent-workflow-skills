# 开源就绪核对

明确拟分发根目录，检查实际技能/项目结构、引用、脚本、文档和组合清单。公开副本排除或脱敏已确认含秘密、未获公开授权的私人身份、本机用户路径、私有业务/用户内容及会话凭据的材料；不能按图片类型或“用户名”字样一概删除。必要的公开作者/仓库标识、版权与许可声明，以及获许可且不含私密信息的 logo、截图和资源应保留。核对逐来源/逐文件许可，未知许可不复制实现；来源固定版本并记录取舍。处理分发副本不授权删除项目原文件。

用实际验证工具检查格式、内部引用、资源与隐私模式；对脚本运行正常和失败路径，只在外部临时夹具验证，不强制引入测试框架。文档区分格式兼容、实际本机运行、代理端到端验证与未知。准备可公开的文件和验收结果不授权远端建库、push、发布或发消息。
