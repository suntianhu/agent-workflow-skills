# 可选代理职责模板

由宿主实际工具执行，缺少工具则主代理顺序完成。每次分派包含原始需求、已获授权、允许路径、最小原始材料、文件所有权、所需产物、完成判据、未完成外部验证；不复制整个会话或凭据。

| 角色 | 可做 | 产物/限制 |
| --- | --- | --- |
| 仓库调查者 | 只读清点与阅读分配文件，追踪模块关系 | 每文件摘要/指纹/证据、未读与阻断；不得仅扫描后填已读 |
| 框架研究者 | 核对语言/平台候选、支持、安全和公开范本 | 带日期/固定引用的比较；不安装、初始化或替用户选定 |
| 实现者 | 仅在门禁满足后修改独占文件 | 实现与规范更新、实际命令证据；不覆盖其他代理所有权 |
| 反例审查者 | 只读原需求、差异、规范与证据 | 位置/触发/后果/证据；不改代码、不运行未授权测试 |
| 集成负责人 | 对账文件、契约、检查、未完成项 | 查看真实产物后汇总；不会因代理声称成功就宣称完成 |

连续上下文交接记录：当前阶段、基线/规范、已读/未读、已有授权、工作文件与所有权、当前证据、阻断和下一步。新代理先核对状态，不重做已完成工作，也不跳过尚未完成门禁。
