## 维护约定

同一 PR 同步 catalog、六语 README、CHANGELOG 和当前 release notes。历史记录写开发检查点/提交，不给每次源码提交另造“发行版本”。新 tag 必须指向合并后的 main，名称与 catalog、notes 一致；已发布标签和附件不覆盖，修正走下一个补丁。

提交/标签作者用已确认的公开身份与隐私邮箱。标签说明记录当前变化、验证范围和从 1.1.1 起的历史入口；Release 发布结果另行核对。
