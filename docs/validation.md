## 1.1.2 发布前 Git 换行修复

首次远端CI在Linux报告52个生成文件散列不匹配，在Windows报告生成入口过期。根因是本地Git的core.autocrlf=true改变提交/检出时的字节，而清单按原文件字节生成；之前本地检查没有覆盖这个环节。

修复：使用.gitattributes强制文本LF，统一源文件换行后重新生成全部技能与散列，校验器允许该标准仓库配置文件。保留逐字节新鲜度和SHA-256要求，没有通过忽略差异放宽检查。六语README同步改为查看真实CI结果，不再声称尚未运行远端CI。

本次实际验证：两个仓库外新克隆分别使用core.autocrlf=true和false，均通过结构校验；两者重新生成技能后的散列均不变。这是同一Windows主机上的Git检出策略验证，不冒称Linux实机测试。实际Windows/Linux结果由本次修复PR与main的GitHubActions记录提供。

该修复发生在v1.1.2首次发布之前，发布ZIP和校验文件将按最终发布提交重新生成。未新增持久测试框架或改变24个技能的职责与8套组合的条件。
