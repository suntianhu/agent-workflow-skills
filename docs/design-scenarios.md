# 设计技能合成场景核对

## 1.4.1 单页设计与老项目连续性

日期：2026-10-19。先由只读基线执行者读取旧指南回答 A–C，再由另一执行者读取修订指南回答 A–D，并定向复核 E–F；另做独立集成审查。基线执行者能选择合理范围，但指出“老项目先看稿”与组合全仓条件的口径张力，以及独立单页需自行推断为非产品工程。本轮是明确分流，不能由少量回答宣称测得效果提升。

| 场景 | 新版拟采用流程与停止位置 |
| --- | --- |
| A 无项目、只设计预约页，先看效果 | 最小简报→必要参考→可查看稿；不先选产品栈、建工程或整套规范 |
| B 已有 WPF、docs/team，只先看录入稿，全仓未读完 | 先看现有页面与规范/组件/样式，继承原设计；可先交有条件草案，不声称开发门禁已过 |
| C 已批准稿直接接入老小程序，全仓未读完 | 不重开已批准设计，但先补全仓理解与内部规范，再实施；批准稿不能代替接入门禁 |
| D 独立 HTML，模拟状态、不装框架、保留交付 | 在 UI 范围制作；写可运行代码前定局部核对/保留，交付 HTML 与临时验证分开收尾 |
| E 同 D，但用户明确要求 TDD | 在真实原型范围执行所需 TDD，不触发产品 TDD/栈/全仓约束；保留原型不自动授权永久套件 |
| F 老产品无 DESIGN.md，新售后页放仓外，模板与旧主色/字体/导航不符 | 新业务/仓外产物仍归老产品；先看旧页面与组件样式，冲突皮肤不采纳；缺旧视觉证据仅交有条件结构稿 |

独立审查发现初始 TDD 条件会把显式 TDD 原型送回产品门禁，已将组合 TDD 限正式实施，原型留在 UI 范围；定向复核未发现剩余实质问题。前向复核指出的验证时机和临时资产措辞也已收敛。用户另明确：即使业务完全不同，仍继承项目全局字体/字级、主题、颜色、间距及基础组件；相关规则落实到 UI、设计规范、参考与单页指南，不能以找不到相似业务页放开全局风格。

执行者没有读取真实产品资料、查看真实旧页面、制作或运行原型；这些是范围/门禁的只读判断，不是视觉一致性或产品功能验收。[结构/导出记录](../provenance/standalone-checks.json)和[离线工具记录](../provenance/offline-examples-1.4.1.json)另列。

## 1.4.0 跨平台基线

日期：2026-10-19，版本 1.4.0。先冻结旧版需求、UI、设计细则和项目规范四份指南，由独立只读执行者回答四个场景；再由另一执行者读取新版相关指南回答同样场景，未提供基线答案。另做一次独立只读集成审查。

| 场景 | 旧版可遵守的边界 | 新版明确补充的执行依据 |
| --- | --- | --- |
| 已有微信小程序品牌/项目 Skill，预约局部变化，给网页 Dribbble 截图且缺错误状态，要求头脑风暴/UIUX | 继承品牌与规范；截图不代表真实状态；不换栈；分别验证 | 头脑风暴条件、参考层级/已看与未操作、微信导航/授权/键盘调查项、局部规则不重建体系 |
| 新 Android 已选 Kotlin，需要整体规范，参考建议带入 iOS 手势/改 Expo | 已选栈先行；平台不可互搬；新体系形成共用规则 | Kotlin 不推定 View/Compose；参考不授权换栈；Android 映射、模板与采纳记录 |
| 老 WPF 密集录入，已有 docs/team，晚启用 UI | 原规范唯一入口；后启技能承接采纳表；键盘/焦点与密度按任务 | 桌面栈证据区别于 WinUI/Web、平台细项、共用/局部边界与原位置引用 |
| 纯 API 内部分页 bug，无界面 | 行为契约与局部验证，无需视觉稿 | 设计参考、整体体系、UI 三段均明确跳过，不加载图库/UIUX |

两轮回答均能守住主要门禁；旧版也能依靠既有原则及执行者知识作出合理安排。新版明确来源层级、平台细项、规范归属和条件交接，**不能由一个基线/新版回答宣称测得效果提升**。具体键盘操作或分页边界仍需真实项目资料判断。

执行者只读指南并提出拟采用流程，没有实际打开目标项目、用户截图、外部产品、UIUX 数据库或官方设计网页，没有渲染界面、操作预约、运行 WPF/Android 或确认 API 根因。资料研究与本仓库工具检查由维护阶段单列，场景回答不能冒充这些证据。

独立集成审查未发现可定位的实质问题。指南进一步明确原型分支：文本/静态线框可先行，代码原型/自动交互前先取得或承接同一次验证决定，后续阶段复用；不自动增加 TDD 或永久测试。

结构、八组合逐文件导出、四个合成项目入口路径和新增上游散列检查见 [design-checks.json](../provenance/design-checks.json)，离线工具示例见 [offline-examples-1.4.0.json](../provenance/offline-examples-1.4.0.json)。这些不是 Java、前端或原生产品功能测试。
