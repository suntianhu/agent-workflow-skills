# 技能采纳判断

用最少适用技能形成一致工作流。

用户明确指定的技能先读；不因关键词或可能性阈值强制加载无关能力。

沿用当前项目规范、有效基线及验证决定，缺口才补。改写、合并或替换用户已有 Skill，先展示具体差异并获明确确认；已确认范围直接沿用。只使用本次获授权的工具与操作。

## 执行

1. 按目标/产物/平台/风险筛选主要能力；承接项目已有规则与已读资料，只补真实缺口。
2. 已有或部分完成的项目Skill先评估复用/局部调整/合并/重建；改文件、资源或入口前展示具体差异并获明确确认。
3. 同职责只保留一个主流程；冲突按当前用户与项目规则收敛，小任务不额外建采纳表或调用其他资源技能。

## 交付

必要的采纳/冲突结论；改用户已有Skill时附具体方案与确认状态。 未核实项如实标注。
