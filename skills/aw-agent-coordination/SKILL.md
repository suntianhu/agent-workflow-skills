# 智能体协作与交接

按真实工具、授权和文件所有权协调。

没有代理工具顺序完成；不把支持多个宿主等同自动启动多个代理。

沿用当前项目规范、有效基线及验证决定，缺口才补。改写、合并或替换用户已有 Skill，先展示具体差异并获明确确认；已确认范围直接沿用。只使用本次获授权的工具与操作。

## 执行

1. 按可独立验收结果梳理任务/依赖与合并点，比较并行收益和协调成本；沿用现有计划，不覆盖其他未完成工作。
2. 按同一任务记录分派最小原始材料、契约/规范、权限/独占写入范围和完成判据，不按技能数创建代理。
3. 主执行者核对实际差异与证据，传递决定来源、工作树状态、有效验证、阻断与下一步；已有授权与未变基线不重置。

## 交付

职责分工、边界、产物核对和交接状态。 未核实项如实标注。
