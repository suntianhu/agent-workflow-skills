# PostgreSQL 数据访问与隔离

仅在实际使用 PostgreSQL、Supabase，或调查其查询、连接、锁和策略时读取。先核对服务器、驱动、连接池及迁移工具版本；其他数据库按自身机制调查。本资料负责数据库细则，项目门禁、测试政策和发布授权沿用当前任务已有决定。

## 从证据选择改动

取得脱敏的实际 SQL、参数分布、数据量、现有索引、排序分页、调用频率和延迟基线。沿调用链区分网络等待、连接池排队、重复查询、执行、锁等待和返回数据传输；不要用新增索引解决所有慢请求。

先看已有统计及获准的执行计划。普通 EXPLAIN 给出估算；EXPLAIN ANALYZE 会真正执行语句，包括函数、触发器及写入副作用。生产诊断须符合具体访问和负载授权，执行型分析优先放在获准的隔离环境；事务回滚不能消除锁、序列、负载或外部副作用。没有生产写入授权时，不执行分析型 DML、建索引或迁移。

对比估计与实际行数、扫描和过滤量、循环次数、排序及缓冲区；顺序扫描可能是小表或高命中比例下的合理计划。缓存、统计和参数分布不同会影响结果；相同条件下比较，再报告观察到的改善，不引用上游示例倍数作本项目收益。

## 查询、分页和索引

- 根据真实过滤、连接、排序与选择性提出索引候选，同时考虑写入、存储和维护成本。组合索引的前导等值、后续范围和排序只是推导起点，按索引类型、实际版本和计划判断；不能声称缺最左列时绝不使用索引。
- 限制返回列和页大小，核对 N+1 与重复计数。深分页可评估游标方案；游标包含排序列及唯一稳定的决胜字段，处理方向、空值、相同排序值与并发变化。兼容既有分页契约，不能承诺恒定耗时或无条件替换 OFFSET。
- 索引、约束和数据回填随版本化迁移交付，核对重复/空值旧数据、锁与超时、并发建索引限制、失败残留和恢复方案。准备迁移文件与在真实库执行分开报告。

## 连接、事务和并发

连接预算按实例上限、应用副本、任务并发、其他客户端和预留连接一起计算，再选择池大小与超时。区分连接获取等待和 SQL 执行超时。确认事务池/会话池对会话状态、临时表和预备语句的实际支持；按驱动、池版本和配置核对，不能套用固定端口、参数名或“事务池一概不支持”的结论。

事务只覆盖必须原子的业务边界，避免持锁等待远端调用；把外部调用移出事务时，同时设计重复调用、查单和补偿，不能牺牲业务一致性来缩短事务。多对象更新约定锁顺序，检查所有相关调用方；单条批量 UPDATE 也不能被当作永不死锁的保证。仅对明确可重试的整个事务做有界重试，并核对幂等和未知提交结果。

## PostgreSQL / Supabase 权限

确认真实连接角色、请求令牌、角色继承、表/列授权、策略适用角色及 USING / WITH CHECK。服务端先验证用户对租户的成员关系，再形成查询条件；客户端 tenant_id 和前端过滤不构成隔离。

RLS 需要在实际请求身份下核实。表所有者、超级用户或 BYPASSRLS 角色可能绕过策略；不能用管理连接的结果证明普通用户隔离。Supabase 管理密钥只用于服务端，核对最终请求是否携带用户令牌及实际角色，不仅凭初始化密钥推断是否绕过 RLS。

检查策略中的查询与函数成本。仅当函数结果与当前行无关时，才评估把身份函数提升为语句级求值；不能把依赖行值的成员判断缓存成所有行相同结果。SECURITY DEFINER 按其所有者权限、search_path、可执行授权和访问对象逐项核实，不把它视为通用加速开关。

## 局部验证与交付

在当前测试政策允许的环境核对本次适用的本人/其他租户、无权限、读/写策略、分页边界、重复/并发和迁移兼容。P0 不运行自动化；P1 不因此新增持久套件。没有真实数据库、代表性数据或请求身份时，交付静态依据与可执行复核步骤，标明未实测。

例如“租户内按时间倒序列表变慢”：先确认主体与租户关系、实际 SQL 与稳定排序，再评估匹配租户和排序的索引；用相同身份和数据条件比较计划、返回行和延迟。新增索引不能代替租户隔离，迁移已编写不能代替迁移已执行。

来源为 Supabase 选定规则的抽象整理，未复制 SQL 示例。具体适用性以目标版本官方资料为准：[EXPLAIN](https://www.postgresql.org/docs/current/using-explain.html)、[组合索引](https://www.postgresql.org/docs/current/indexes-multicolumn.html)、[连接池能力](https://www.pgbouncer.org/features.html)、[Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security)。
