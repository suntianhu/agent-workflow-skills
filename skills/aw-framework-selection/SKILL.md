# 新项目框架选型

推荐适配、受支持、较新稳定且已核对已知风险的候选。

用户已选定或明确委托自主选型后方可初始化；委托时记录依据并继续，未获委托时无回复不是选择，已有有效决定不重复询问。

沿用当前项目规范、有效基线及验证决定，缺口才补。改写、合并或替换用户已有 Skill，先展示具体差异并获明确确认；已确认范围直接沿用。只使用本次获授权的工具与操作。

## 执行

1. 确认语言、平台、需求和部署约束；前后端分别比较。
2. 打开官方支持/发布、安全公告与公开仓库证据，给2–3候选及日期/许可/风险/成本。
3. 用户选定或在明确委托范围内完成选择后，交付语言、框架、版本证据、限制与决策来源，交接GitHub范本研究和项目规范；本技能不初始化代码或重复编写规范。

## 交付

带直接来源的候选表、推荐依据、用户选择或待决事项。 未核实项如实标注。
