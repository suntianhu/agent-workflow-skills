# 新项目框架选型

推荐适配、受支持、较新稳定且已核对已知风险的候选。

## 前置条件与边界

必须用户选择后初始化；无回复不是选择，已有明确选择不重复询问。 遵从当前用户、适用项目规则与宿主权限；不因技能存在扩大任务或外部写入授权，已有授权继续执行。

进入已有项目时读取当前项目规则与既有内部规范，承接已完成的梳理、技能采纳和验证决定。后续启用本技能也先核对这些记录；发现冲突先收敛到同一规范入口，不另起脱节流程。

## 执行

1. 确认语言、平台、需求和部署约束；前后端分别比较。
2. 打开官方支持/发布、安全公告与公开仓库证据，给2–3候选及日期/许可/风险/成本。
3. 用户选择后交付选中语言、框架、版本证据与限制，交接GitHub范本研究和项目规范；本技能不初始化代码或重复编写规范。

## 必须得到的结果

带直接来源的候选表、推荐依据、用户选择或待决事项。 没有证据的项目标为未核实，不补写完成结论。
