# 设计参考研究与采纳

将适用参考转为有阅读证据的采纳决定。

## 前置条件与边界

既有规范与选定平台先行；图库不证明交互、可访问性或素材许可，不为参考更换技术栈。 遵从当前用户、适用项目规则与宿主权限；不因技能存在扩大任务或外部写入授权，已有授权继续执行。

进入已有项目时读取当前项目规则与既有内部规范，承接已完成的梳理、技能采纳和验证决定。后续启用本技能也先核对这些记录；发现冲突先收敛到同一规范入口，不另起脱节流程。

## 执行

1. 先明确待解问题、简报与已有品牌/规范；按项目、平台官方、成熟系统、真实产品与灵感分层取证。
2. 记录实际已读/已看/已操作、版本/日期与缺口；借鉴原则并写明调整、不采纳及许可边界。
3. 共用决定交给同一项目设计规范，局部方向交给页面设计；证据够用即停止搜索。

## 必须得到的结果

来源/采纳表、推荐方向、适配与许可边界、规范或页面落点。 没有证据的项目标为未核实，不补写完成结论。
