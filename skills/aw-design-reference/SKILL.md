# 设计参考研究与采纳

将适用参考转为有阅读证据的采纳决定。

既有规范与选定平台先行；图库不证明交互、可访问性或素材许可，不为参考更换技术栈。

沿用当前项目规范、有效基线及验证决定，缺口才补。改写、合并或替换用户已有 Skill，先展示具体差异并获明确确认；已确认范围直接沿用。只使用本次获授权的工具与操作。

## 执行

1. 先明确待解问题、简报与已有品牌/规范；按项目、平台官方、成熟系统、真实产品与灵感分层取证。
2. 记录实际已读/已看/已操作、版本/日期与缺口；借鉴原则并写明调整、不采纳及许可边界。
3. 共用决定交给同一项目设计规范，局部方向交给页面设计；证据够用即停止搜索。

## 交付

来源/采纳表、推荐方向、适配与许可边界、规范或页面落点。 未核实项如实标注。
