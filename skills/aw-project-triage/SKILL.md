# 项目识别与开发门禁

先区分设计稿、独立原型与正式实施，再判断项目、影响端和门禁。

设计/调查/独立原型按范围产出；老项目正式实施先核实现行完整基线、差异和规范，缺覆盖才补全，新产品未选栈不初始化。

沿用当前项目规范、有效基线及验证决定，缺口才补。改写、合并或替换用户已有 Skill，先展示具体差异并获明确确认；已确认范围直接沿用。只使用本次获授权的工具与操作。

## 执行

1. 先识别交付与停止位置；属于老产品就读现有规则、技能入口及相关旧页面/组件/样式，新需求或仓库外原型不等于从零设计。
2. 正式实施再判新旧、前后端/跨端与风险；老项目全仓门禁保留，独立原型不改产品代码或真实业务。
3. 列出前置产物、仍缺决策、允许独立推进的工作；不为已有授权重复确认。

## 交付

交付类型与停止位置、目标项目/影响端、适用门禁和下一步。 未核实项如实标注。
