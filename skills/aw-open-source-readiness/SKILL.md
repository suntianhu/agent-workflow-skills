# 开源就绪检查

形成可公开审阅的规范产物。

## 前置条件与边界

本地准备不等于授权远端建库、push或发布。 遵从当前用户、适用项目规则与宿主权限；不因技能存在扩大任务或外部写入授权，已有授权继续执行。

## 执行

1. 核对分发根、格式、引用、来源与逐文件许可。
2. 检查私有业务、本机路径、秘密与多代理依赖。
3. 运行结构和工具核验，列清已测/未测与发布门槛。

## 必须得到的结果

公开就绪文件、许可/来源与验收报告。 没有证据的项目标为未核实，不补写完成结论。
