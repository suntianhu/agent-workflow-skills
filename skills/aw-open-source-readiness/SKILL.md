# 开源就绪检查

形成可公开审阅的规范产物。

本地准备不等于授权远端建库、push或发布。

沿用当前项目规范、有效基线及验证决定，缺口才补。改写、合并或替换用户已有 Skill，先展示具体差异并获明确确认；已确认范围直接沿用。只使用本次获授权的工具与操作。

## 执行

1. 核对分发根、格式、引用、来源与逐文件许可。
2. 检查私有业务、本机路径、秘密与多代理依赖。
3. 运行结构和工具核验，列清已测/未测与发布门槛。

## 交付

公开就绪文件、许可/来源与验收报告。 未核实项如实标注。
