# 需求驱动视觉设计

按实际范围交付可查看的页面/流程设计或原型。

属于老产品就先看旧设计并继承全局字体/样式，业务不同或缺文档不例外；无目标项目可独立设计，正式接入另按开发门禁。

沿用当前项目规范、有效基线及验证决定，缺口才补。改写、合并或替换用户已有 Skill，先展示具体差异并获明确确认；已确认范围直接沿用。只使用本次获授权的工具与操作。

## 执行

1. 先判交付范围；老产品先查看相关旧页面/预览或截图与组件/样式，即使无书面规范也继承原设计；单页/原型按 standalone-page.md。
2. 复用可用规则，本页补够用的局部视觉/状态/原型；平台细则按需，共用变更写回实际项目规范。
3. 要求看效果时交可查看产物；老项目与旧页面对照连续性，缺关键视觉证据只交有条件草案，未预览不冒称已看。

## 交付

符合所需格式的可查看页面/流程稿或原型、适用状态、假设/示例说明、实际核对范围与停止位置。 未核实项如实标注。
