# 证据与结论



| 能说的结论 | 需要的证据 |
| --- | --- |
| 格式/lint/类型/构建通过 | 对应命令、范围、退出码与实际输出 |
| 行为已局部验证 | 真实操作或符合策略的校验，明确正常/失败/恢复哪些路径 |
| 缺陷已复现并修复 | 已观察的原始症状及修复后相同触发的结果 |
| 真实云/客户端/生产验收 | 对应真实环境与身份的实际调用结果 |

本次最终实现后的检查证据可复用；没有新变更或疑点不机械重跑全量命令。代理总结、编译成功、模拟页和代码推演只能支持各自范围。

浏览器证据应对应最终页面与实际断言，标明 mock/拦截、环境和身份范围；点击或录制成功不直接支持业务成功。数据库证据分别标明估算计划、实际执行、迁移准备和迁移执行，不能用管理身份结果证明普通用户隔离。核对证据不自动启动缺失的浏览器/数据库操作。

交付报告按任务大小简述：结果和文件、实际命令及结果、行为覆盖与回归记录、未完成外部验证/风险、实际耗时和估时偏差。轻微改动压缩到必要几句；不要虚构“全量测试通过”。
