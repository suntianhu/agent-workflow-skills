# 项目内规范与公开参考

规范必须位于实际目标项目内，开发时可发现、可追溯并保持更新；本技能集合不能代替每个项目自己的规范。已有规范入口优先使用，内容不足则补全，不制造互相矛盾的第二份。

默认位置 `docs/engineering/PROJECT_STANDARDS.md`，前后端内容可拆为FRONTEND.md与BACKEND.md。使用本包 `assets/project-standards.md` 的字段结构填入真实内容，删除不适用章节并说明依据；未读/未知不能改写成事实。

老项目规范来源于本轮全仓代码理解、配置与用户决策；新项目来源于用户选定的语言/框架、实际官方文档与成熟GitHub范本。两类都记录日期、版本/提交、规则证据、例外、检查命令和变更维护方式。开发前读取相关章节，提交前核对代码/文档偏差；规则要改变时先明确新决策再同步。
