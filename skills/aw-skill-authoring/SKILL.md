# 技能编写与维护

保持单一职责、可发现、可组合、可验证。

## 前置条件与边界

不捆绑特定代理工具或私有产品，不伪造评测效果。 遵从当前用户、适用项目规则与宿主权限；不因技能存在扩大任务或外部写入授权，已有授权继续执行。

进入已有项目时读取当前项目规则与既有内部规范，承接已完成的梳理、技能采纳和验证决定。后续启用本技能也先核对这些记录；发现冲突先收敛到同一规范入口，不另起脱节流程。

## 执行

1. 确认触发/排除/输入输出与真实用户需要。
2. 保持短入口与按需参考，脚本实际运行，模板显式标记用途。
3. 验证结构/链接/工具及真实边界，维护来源和采纳理由。

## 必须得到的结果

标准技能文件、必要资源与真实验证范围。 没有证据的项目标为未核实，不补写完成结论。
