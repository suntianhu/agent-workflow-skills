# 技能编写与维护

保持单一职责、可发现、可组合、可验证。

遵从真实维护源；部分技能不自动覆盖，修改用户已有Skill/资源/入口先展示具体方案并获明确确认，不伪造效果。

沿用当前项目规范、有效基线及验证决定，缺口才补。改写、合并或替换用户已有 Skill，先展示具体差异并获明确确认；已确认范围直接沿用。只使用本次获授权的工具与操作。

## 执行

1. 确认触发/排除/输入输出与真实用户需要。
2. 保持短入口与按需参考，脚本实际运行，模板显式标记用途。
3. 验证结构/链接/工具及真实边界，维护来源和采纳理由。

## 交付

标准技能文件、必要资源与真实验证范围。 未核实项如实标注。
