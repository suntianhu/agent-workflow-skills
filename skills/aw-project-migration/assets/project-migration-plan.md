# 项目迁移计划模板

用途：填写真实项目的迁移决定、保留映射、依赖与验收。已有等效记录直接引用；删除不适用段落。此模板不是已执行证据，不填写凭据或生产个人数据。

## 范围与决定

- 交付范围/停止位置：只读分析 / 本地实施 / 隔离演练 / 已授权切换（写具体授权）。
- 业务目标、当前痛点、成功条件和非目标：
- 原项目/目标位置、源代码基线和完整阅读/差异记录：
- 同一项目规范、既有 Skills、验证/TDD/保留决定：
- 旧/新前端、管理端、服务端、数据库/ORM、调度/队列及部署：
- 已确定目标及决定来源；尚需选择的候选/官方版本证据：
- 停机/停写窗口、容量、预算、旧客户端期限、RPO/RTO：
- 选定迁移路径、过渡成本、保留资产、未决项与负责人：
