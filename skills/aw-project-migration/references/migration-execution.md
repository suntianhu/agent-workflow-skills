# 迁移共存、数据搬迁与切换

只执行当前已授权范围内的本地实现、演练或真实操作。制定计划不自动授权生产停写、外部副作用、删表、停服务或发布；已有具体授权直接承接。以项目既有验证政策确定检查与产物保留，不因“迁移”统一改成 TDD、全量永久测试或复制生产数据库。

## 共存契约与兼容矩阵

明确请求路由、身份/会话、缓存、数据与任务的归属，避免新旧系统循环代理或读取长期不更新的副本。对旧/新调用方 × 旧/新服务 × 各阶段 schema 列出“必须支持 / 不适用及理由 / 已验证 / 未验证”，不要求部署永不同时存在的组合。数据库版本回退与代码回退分别评估。

用旧行为样本和消费者契约建立比较基线。对随机 ID、时间戳等动态字段只做有依据的归一化，不能把真实业务差异排除掉。对每项批准改变的行为单列期望值，不用“完全一致”覆盖有意修正。涉及真实写入的对比先解决副作用隔离，不能为了验证执行两次业务。

同库事务内的多字段更新与跨库/消息系统双写分开判断。按实体或分区指定权威写入方及读一致性要求，评估停写窗口、复制、CDC、事务 outbox 或可恢复同步；不默认新旧两库各写一次就一致。用 outbox/事件也需处理重复、顺序、失败重放和消费者幂等，不能声称因此自动 exactly-once。只在需求要求时引入这些设施。

## 数据迁移的可恢复步骤

1. **预检和映射：** 固定源/目标版本、迁移脚本和配置结构；确认只读盘点与写入身份、空间/容量、非法数据处理、约束、查询/锁影响，以及备份可用性。实际恢复演练和“备份命令成功”分别记证据。
2. **兼容扩展：** 涉及并行读写时，先部署兼容新旧读写者的结构/适配层；增加列/索引也可能锁表、重写或增加资源消耗，按实际引擎/版本验证，不能一概视为安全。目标已停止旧版本且有明确窗口时可使用更简单的替换方案。
3. **复制或回填：** 选择全量、分批或增量方式。在线搬迁把快照与变更流锚定到可追踪的一致点，记录水位/游标、并发更新/删除、重试和冲突规则，避免快照完成到开始采集间丢变更。分批处理需限速、检查点和重入去重，旧快照不能覆盖较新的值或复活已删记录；离线停写方案注明写冻结边界。
4. **对账：** 在相同水位/一致性边界上比较完整性、字段与业务准确性、关系约束、时效与增量延迟。包含数量、分区/租户/时间段、关键金额/状态汇总、适用校验值及边界/抽样记录；行数相同不能证明内容相同。差异需定位/修复/获准解释，关键差异未清不能切换。
5. **切换写入：** 先准备 schema/约束/序列/权限与文件引用，按运行手册暂停或隔离全部旧写入口（含任务、手工脚本及旧实例），排空在途工作，追平最终增量并对账，再转移写入权。按选定策略切路由/读流量/任务，核对首次新增、更新和删除。真正可协调的并行切换需给等效一致性证据，不机械要求全站停机。
6. **观察与收缩：** 按风险和最长相关业务周期设置观察窗口，监控消费者错误、延迟、队列、任务和业务指标。满足退役条件后再清理旧结构、兼容层、运行配置和依赖；未获授权或尚需保留的资产列责任人与后续条件，不把待退役报成全量迁移完成。

跨数据库引擎时，逻辑复制/导入的能力不能推广为全部 schema、序列、触发器或文件都已同步。例如 PostgreSQL 18 官方列明逻辑复制不传递 DDL 与序列状态；这只是该版本的具体例子，实际项目按引擎、工具和版本复核。

## 恢复不是一个“回滚”按钮

逐步写明失败检测、停止点、负责人、可用恢复手段及数据边界。区分撤回代码/路由、反向迁移或同步新写、从备份恢复、向前修复/业务补偿，以及没有可行逆向恢复的步骤；这些方式可组合，不硬分成只能选一种。

新系统已接受写入后，旧库可能落后或无法表达新状态。回旧版本前核实旧代码兼容当前 schema、所有新写可同步/保留、任务与回调不会重放副作用；若条件不成立，停止继续切换并按已选方案向前修复或恢复，而不是盲切旧库。备份恢复要说明恢复点之后的写入怎样处理，不能悄悄丢弃已完成交易。不能假定所有数据迁移都有无损 down 脚本。

不可逆转换、删除或无法补偿的外部效果执行前，需有其具体影响的明确授权与应急处置；前置代码、差异、演练证据及操作步骤先准备到可审阅状态。不为普通可逆本地改动新增审批。

## 每批验收和最终状态

每批检查适用保留项、消费者兼容、权限/租户隔离、数据对账、任务不漏不重、失败与恢复、受影响正常业务、资源/性能基线；阈值与窗口来自项目约束和基线，不写固定百分比、天数或覆盖率。性能检查在授权环境执行。审查只读，发现缺口交回负责的实现者。

状态按证据区分：方案已交付、实现完成、隔离演练通过、已部署待观察、已切换、旧路径已退役。要报告“全量迁移完成”，保留项必须都有处置和验收，旧消费者与写入口已按方案处理，数据/任务运行和恢复证据覆盖最终产物。计划、模拟、代理汇报、源码扫描分别不能代替真实环境执行证据；没有环境时交付可执行手册并列出待核对项，不虚报成功。
